# 🌟 Meu Primeiro Projeto - Portfólio

Este é o meu primeiro projeto desenvolvido com a ajuda do curso **Viver de Código**.  
Trata-se de um portfólio simples feito com **HTML** e **CSS**, que apresenta meu perfil e as habilidades que adquiri ao longo do curso.

## 🚀 Tecnologias usadas
- HTML5
- CSS3

## 📸 Sobre o projeto
O objetivo deste portfólio é praticar os conceitos básicos de **HTML e CSS** e criar uma página que:
- Apresente meu nome e perfil
- Mostre minhas habilidades
- Tenha um layout simples e organizado
