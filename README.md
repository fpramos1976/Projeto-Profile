# 🌟 Meu Primeiro Projeto - Portfólio

Este é o meu primeiro projeto desenvolvido com a ajuda do curso **Viver de Código**.
Trata-se de um portfólio feito com **HTML**, **CSS** e **JavaScript**, que apresenta meu perfil, minha stack, meus projetos e formas de contato.

## 🚀 Tecnologias usadas
- HTML5 (semântico e acessível)
- CSS3 (variáveis CSS, Flexbox, Grid e media queries)
- JavaScript (tema claro/escuro salvo no navegador)

## ✨ Funcionalidades
- Layout responsivo (desktop, tablet e celular)
- Tema claro/escuro, que segue o tema do sistema e lembra a escolha do visitante
- Destaque da página atual no menu
- Links externos abrindo em nova aba com segurança (`rel="noopener noreferrer"`)

## 📁 Estrutura
```
├── index.html      # Página inicial (banner, stack e projetos)
├── about.html      # Sobre mim, experiência e formação
├── stack.html      # Tecnologias
├── project.html    # Projetos
├── contact.html    # Contato
├── css/
│   ├── _variables.css  # Cores, pesos de fonte e temas
│   └── main.css        # Estilos principais
└── assets/
    ├── main.js     # Tema claro/escuro
    └── images/
```

## ▶️ Como rodar
Basta abrir o `index.html` no navegador, ou usar a extensão **Live Server** do VS Code.

## 🌐 Publicar no GitHub Pages
Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
O site ficará em `https://fpramos1976.github.io/Projeto-Profile/`.
